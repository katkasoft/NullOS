NullOS v0.1 help
List of all available commands:

Shell commands:
cd [dir] - Change working directory
pwd - Print working directory
echo [text] - Print text
clear - Clear screen
export [VAR=value] - Set environment variable
unset [VAR] - Remove environment variable
env - Print all environment variables
exit - Exit shell

File management:
ls [dir] - List files and directories in directory
touch [file] - Create file or update modified and accessed time
cat [file] - Read contents of file
tac [file] - Read contents of file, reversed by lines
write [file] [contents] - Write to file
rm [file/dir] - Remove file or directory
mkdir [dir] - Create empty directory
rmdir [dir] - Remove empty directory
cp [file/dir] [destination] - Copy file or directory
mv [file] [destination] - Move or rename file
head [file] - Read first lines of file
tail [file] - Read last lines of file
wc [-l|-w|-c|-m] [file] - Count lines, words, bytes or chars
find [dir] [name] - Search for files in directory
nl [file] - Number lines of file

System (kernel) commands:
sysmanager reboot/restart - Reboot system
sysmanager shutdown/poweroff - Power off system
sysmanager halt - Halt system
uname - Print kernel version
syscall [number] [args...] - Invoke kernel syscall directly
sync - Flush filesystem buffers to disk
uptime - Show how long the system has been running

Process management:
ps - List all processes and their stats
kill -[signal] [pid] - Kill process by pid
killall -[signal] [process] - Kill all processes by name

Other commands:
id - Print user and group identity
whoami - Print current user name
hostname - Print system hostname
sleep [seconds] - Pause for given number of seconds
help [command] - Display manual for command(s)
