rsh - NullOS shell

Usage:
    rsh
    rsh -c [command]
    rsh [script]

The NullOS command shell.

Without arguments, starts an interactive shell with history
(arrow keys to navigate).

With -c, executes the given command and exits.

With a script path, executes the script line by line and exits.
Lines starting with # are ignored as comments.
Multiple scripts can be passed and will run in order.

On interactive startup, rsh runs:
    /etc/rshrc       - system-wide config
    $HOME/.rshrc     - user config

Built-in commands:
    cd [dir]         - change directory (no args -> $HOME)
    pwd              - print working directory
    echo [text]      - print text
    clear            - clear the screen
    export [VAR=val] - set environment variable
    unset [VAR]      - remove environment variable
    env              - print all environment variables
    exit             - exit the shell

Environment:
    Variables are stored in the shell and inherited by child processes.
    Use export VAR=value to set, unset VAR to remove, env to list all.
    $VAR in command arguments is replaced with the variable value.
    External commands are searched using the PATH variable.

External commands are searched in /bin, /sbin and /usr/bin.
